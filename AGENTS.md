# Instruções do repositório

- O projeto é um site estático em `public/`, sem backend, banco de dados ou build.
- Use HTML, CSS e JavaScript puro; Chart.js e Papa Parse são dependências de CDN com versão fixada.
- A demonstração embutida em `public/script.js` deve corresponder a `public/dados-exemplo.csv`.
- Preserve `vendas_hamburgueria.csv`, a base original fornecida para a atividade.
- Mantenha a interface em português do Brasil e as métricas derivadas das linhas filtradas.
- O `README.md` documenta o uso local, o formato de importação e a publicação no Render Static Site.
